# Install guacamole

In this section, we show a procedure to install an instance of `guacamole` install in `Debian OS` (All installation are made in VM on MacOS ARM).

The version of guacamole install by this script is 1.5.5 (actually the last version is 1.6.0, but the choise of an old version to create an upgrade script).

> That's importante to know, Guacamole needs tomcat9 and not tomcat10
